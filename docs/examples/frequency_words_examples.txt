# =============================================================================
# TIPS FOR CUSTOMIZATION
# =============================================================================
#
# 1. START SIMPLE:
#    Begin with 5-10 keywords, run for a few days, then refine
#
# 2. USE GROUPS:
#    Separate different interests with empty lines for better organization
#
# 3. ADD FILTERS GRADUALLY:
#    Only add !filters when you see unwanted content appearing
#
# 4. REQUIRED WORDS ARE POWERFUL:
#    Use + to narrow scope (e.g., +launch limits to launch news only)
#
# 5. PRIORITY MATTERS:
#    Put most important keywords at the top of each group
#
# 6. TEST AND ITERATE:
#    Check your notifications for a week, adjust as needed
#
# 7. AVOID OVER-FILTERING:
#    Too many filters = miss important news
#
# 8. CASE INSENSITIVE:
#    "Apple" matches "apple", "APPLE", "Apple"
#
# 9. PARTIAL MATCHING:
#    "phone" matches "smartphone", "iPhone", "telephone"
#
# 10. EMPTY FILE = ALL NEWS:
#     Leaving file empty sends ALL trending news (very high volume!)
#
